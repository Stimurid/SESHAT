# SESHAT — Universal Analytic Fabric

SESHAT is the shared analytic runtime for the AI ecosystem.

It is **not** the Sechenovka authorabstract machine. Sechenovka is the first full domain profile and evaluation host.

SESHAT exists to remove duplicated analytic plumbing from independent systems such as Socrates, LitOps, Tinkuy, Quinta/AgentRun, D20, Indago, PRAGMA/Paideia and later hosts, while preserving their own methods, authorities and domain semantics.

## Boundary

SESHAT owns reusable analytic execution contracts and mechanics:

- ResearchObject / SourceCarrier / SourceAddress
- Observation / CutSpec
- AnalyticObjectSpec
- EvidenceAccessProfile / RawAccessPolicy
- OperationSpec / MethodologicalFrame
- DerivedObject + version + lineage
- dependency / invalidation
- applicability / APORIA
- acceptance / decision rights
- ResearchNeed / EvidenceReturn
- projections
- run trace / budget / persistence

SESHAT does **not** absorb its donor/consumer systems. Socrates, LitOps, Tinkuy, Quinta, D20, Indago, PRAGMA/Paideia and Sechenovka remain independently governed bodies. SESHAT receives reusable implementation through REUSE / WRAP / EXTRACT / COMPLETE and exposes adapters/profiles back to those hosts.

## Architecture layers

1. **Core substrate/runtime** — shared state, evidence, operations, lineage, invalidation, authority and projection contracts.
2. **Reusable operation mechanics** — reconstruction, local extraction, comparison, reconciliation, corpus aggregation, external evidence join, critique, QA, research dispatch and decision projection.
3. **Domain/method profiles** — host-specific analytic objects and methodological bodies, e.g. `sechenovka_authorabstract`.
