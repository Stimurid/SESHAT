# Sechenovka Authorabstract Profile

This is the first full domain profile of SESHAT, not the architectural center of SESHAT.

## Source-authorized historical method bodies

Recovered and validated historical methods exist for:
- Object reconstruction;
- Method reconstruction (Agent-0);
- method novelty/readiness (Agent A, with a known input limitation);
- infrastructure trace (Agent B, with a known input limitation);
- alternatives / limitations / methodological literacy (Agent C).

Missing method bodies are not generated merely because a semantic artifact contract exists.

## Initial analytic operations

### Object
Full-package reconstruction. Functional object may be distributed across problem, methods, results and interpretation.

Target access:
- EAP-FULL+STATE
- RawAccessPolicy: FULL_REQUIRED

### Method
Full-package reconstruction of the actual method machine rather than section parsing.

Target access:
- EAP-FULL+STATE
- RawAccessPolicy: FULL_REQUIRED

### Infrastructure
Distributed dependency reconstruction. Historical Agent B was too method-section-centered.

Target access:
- EAP-FULL+STATE
- RawAccessPolicy: FULL_REQUIRED for initial reconstruction, focused drillback permitted later.

### Novelty
Historical Agent A was bound to Agent-0 method_section and therefore exposed to information loss.

Target access:
- EAP-FULL+STATE
- RawAccessPolicy: FULL_REQUIRED for internal novelty reconstruction;
- external evidence required for world-frontier claims.

### Limitations
Explicit and inferred constraints linked to method, infrastructure, result and claim.

Target access:
- EAP-FULL+STATE

## Known historical topology defect

The old machine used mixed evidence access:
- Object: whole text;
- Agent-0: whole text;
- Agent A: method_section only;
- Agent B: method-centered input;
- Agent C: method section or full authorabstract.

This is a source-observed defect/candidate for repair, not a reason to declare universal full-raw access for every future operation.

## 39-artifact boundary

The semantic/question matrix is broader than the validated method-body set.

Rows without historical methods remain CONTRACT-LEVEL until their methods are designed and tested.
