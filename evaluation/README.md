# Topology Evaluation

Evaluation starts only after minimal executable core contracts exist.

The same source cases must be replayed under comparable topologies.

Initial candidates:
- T1: historical / frozen handoff;
- T2: parallel raw-aware operations;
- T3: shared observations + selective drillback;
- T4: Object <-> Method reconciliation + versioned blackboard.

Compare:
- evidence loss;
- contradiction recovery;
- duplicate reading;
- invalidation precision;
- provenance and contestability;
- runtime/resource cost;
- human-interface tax.

Evaluation is a reproducible repository run, not a collection of unrelated chat prompts.

GitHub Actions are optional later regression infrastructure, not the initial execution substrate.
