## Donor program ordering (do not force into one chain)

**Near-term SESHAT S1/S2/S3:** source identity, raw drillback, original-source method recursion, typed proposals/acceptance, currentness and invalidation. Ingest the *contract* of pre-Hephaestus analysis and negative controls from human-selection falsification.

**Next S5 provider and host adapters:** separately wrap `Hephaestus Critic` and `Paideia Packet`; preserve conceptual/normative case ownership. Provider GigaChat is a replaceable ModelPort; need a working non-GigaChat host profile with same contract.

**S6 long-report test:** seven cluster generation over frozen source/method/dependency snapshots, immutable per-section run results, no `[CLUSTER FAILED]` false pass, explicit surface degradation, source-anchored content review, full document render and actual pagination.

**Paideia replacement** stays [issue #13](https://github.com/Stimurid/SESHAT/issues/13), PARKED until source-complete, quality-accepted SESHAT is proven on a full historical case. No implementation code changed by archaeology.
