III. THREE DISTINCT REPORT ENGINES, NOT A SINGLE TESTED PIPELINE

A. M2 / RC2 longitudinal analysis + seven-cluster prose renderer (real code)
Repo 'Stimurid/paideia@a1a8ee01b64', 'api/dialogue_runtime/orchestrator.py' (~837 lines): twelve typed analysis stages (corpus passport, lineage identity, versions, position reads, discussion, semantic diff, recommendation fate, retrieval, lab requirement/no-build, tension and assembly). 'api/dialogue_runtime/renderer.py' (~1047 lines) renders seven independently generated prose section clusters after a compact shared typed context. Output is deterministically concatenated; every cluster gets same source-derived typed view, not full original author files. Actual report artifact 'reports/regression/rr002_prod_rendered.md' has 78,298 characters and 703 text lines, with 29-section style and report run identifier. Historical M2 implementation report 'docs/PAIDEIA_M2_LONG_REPORT_IMPLEMENTATION_REPORT.md' says locally 65k chars / 30+ pages and earlier server-side completed seven-cluster run; its original 60-page prod validation was still being audited at report date. Do NOT assert 70 pages based on these metrics.
CRITICAL LIMITS in real M2 code: '_build_shared_context(... max_chars=55000)' can truncate discussion slices and context; full source is not re-provided to the section writer; fallback failures insert '[CLUSTER ... FAILED]' but 'render_report' still calculates total sections and 'clusters_used=7' and can persist output to 'analysis_runs_meta.update_run_json.rendered_report_md'. Rerender overwrites prior rendered_report_md rather than persisting an immutable version. Historical report explicitly notes M2 tests largely inherited M1 (38 passing), with no new unit suite for renderer. This is an excellent output-partition donor, NOT a certified no-loss/report acceptance engine. Future SESHAT must gate per-cluster success, report completeness, source drillback, versioned output and incremental invalidation.
Historical method states source package inventory, literal versus strongest benevolent reconstruction, a main carrying break, twenty fields, actor graph, risk of ability substitution, pilot and lab TЗ. These are domain-specific Paideia semantics, NOT the universal ontology.
